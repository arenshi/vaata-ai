# Лица

Сети для режима «Лицо»: одна находит лица, другая делит каждое на части. Саму ретушь — кожу, пятна, тон, блеск,
круги под глазами, белки глаз и зубы — Vaata делает своим алгоритмом по этим маскам, на полном разрешении снимка.

- [`yunet`](yunet) — YuNet, поиск лиц и пяти точек на каждом, MIT.
- [`easyportrait-segformer-b0-512`](easyportrait-segformer-b0-512) — EasyPortrait SegFormer-B0, кожа, брови, глаза,
  губы и зубы; переработка CC BY-SA 4.0 от SberDevices.
